# 对话与审批

[文档首页](../README.md) · [快速开始](getting-started.md)

Mac 的 Dot 面板与手机的 Qoder 网页共用同一会话。切换设备后，可以继续看审批、进度和结果。

## 选择执行位置

| 想做什么 | 可以怎么说 |
| --- | --- |
| 在 QCA 云端处理 | 「让 Qoder 在云端整理这份已上传的笔记」 |
| 交给 Mac 上的 DSH | 「让 D 那边把 `hello dot` 转成大写」 |
| 先讨论任务 | 「帮我把这个想法整理成给 D 的任务，先别执行」 |
| 读取 Mac 的时钟 | 「看一下 Mac 那边的时间」 |

执行位置有歧义时，Dot 会询问用 Mac 还是云端。协商完成后，可以回复「按刚才定的交给 D」。Mac 审查方案后会回传结论，必要时再请你补充目标或确认操作。

「优先让 Mac 做」会先核对桥接和 DSH 是否可用。任务还没投递，且所需资料已在 QCA 时，Mac 掉线后云端助手可以接手。依赖本机文件、既有 DSH 对话或指定只在 Mac 执行的工作会等待 Mac 恢复。投递状态未确认时，先查看原执行端。

## 核对审批

- **云端工具**。QCA 的终端、写入和编辑会显示待审批卡。核对实际参数再允许或拒绝。
- **Mac 任务**。核对卡片上的任务和工作区。需由 DSH 自行决定命令时，先批准任务，再分别核对命令卡。
- **明确指定的 Mac 命令**。「让 D 在 Mac 执行 `printf HELLO`，把输出发回来」这类请求可授权一次执行。Dot 会核对本轮原文、工作区和实际命令。要指定项目，先在 DSH 面板「本地项目」选择已注册的工作区。

手机打开审批卡后，选择「允许」或「拒绝」，再点「提交」。命令卡上的期限从 Mac 启动该终端任务起算，最长 10 分钟。处理中的任务仍在原会话里显示。要中断当前轮，在 Mac 面板点「停止当前轮」，等发送按钮恢复后继续。

## 键盘与外观

- **Enter** 发送，**Shift + Enter** 换行。中文输入法选词时，Enter 用于确认候选词。
- 「设置 → 外观」可切换翡翠绿、DSH 蓝、暖纸和石墨主题。
- 「设置 → 星球」可保留经典头像，或按编号生成并调整自己的星球。主题和星球设置保存在当前浏览器。

遇到状态未确认或审批过期时，按[故障排查](troubleshooting.md)核对原会话。
