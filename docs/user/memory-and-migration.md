# 记忆与会话迁移

[文档首页](../README.md)

## 记录项目偏好

在对话中说「记住 项目偏好 archive-order：按年份排序」。面板的「记忆」页会显示条目和来源，Mac 本机文件在 `.dot-state/<站点>/MEMORY.md`。

- 查询可以说「查一下 Dot 记忆 archive-order」。
- 更新可以说「更新 项目偏好 archive-order：按季度排序」。
- 删除本机条目可以说「忘记 Dot 记忆 archive-order」。旧会话消息会继续保存在 Qoder 历史里。

## 从设置迁移会话

1. 等当前会话空闲，打开「设置 → 会话迁移」，填写新 Agent 名称。
2. 只填写可以存到云端的交接说明。若想把本机记忆另存一份云端快照，勾选上传选项。此后的本机修改或删除只作用于本机记忆。
3. 选择云端记忆权限。已有的 Memory Store 可复用，默认沿用原权限。新建记忆库默认只读。
4. 点「一键创建迁移副本」。Dot 复制会话生效的模型、提示词、技能和工具配置，并验证记忆能在新会话读回。
5. 在设置中点「切换到新会话」，或沿用页面给出的旧会话链接查看原历史。Mac 桥接每次连接一条会话，切换后手机可从 Qoder 会话列表打开新的主会话。

迁移中断时，点「继续这次迁移」沿用已创建的副本。进度在 `.dot-state/<站点>/migration.json` 中。[QCA 持久化记忆](https://docs.qoder.cn/cloud-agents/memory-stores)

## 修复 Dot 配置

在面板「设置 → Agent 配置」点「检查并修复 Dot 配置」，也可以在对话中说同一句话。Dot 等当前轮结束后核对配置。缺少云端助手时，会创建迁移副本并核对云端记忆和真实子线程回执，验证后切换。手动切回的旧会话会保持该选择，可按需主动修复。

Mac 离线时，对话中的请求会留在原会话。重连后 Dot 会恢复最近一条符合条件的请求。说「查看 Dot 维护状态」可以查看进度。
