# 任务本与结果

[文档首页](../README.md) · [对话与审批](chat-and-approvals.md)

在 Mac 面板点「任务本」。搜索框可输入标题、任务 ID 或回执，再按类型和状态缩小范围。列表覆盖当前载入的近期 DSH 对话、QCA 子线程和从 Dot 发出的任务。更早的 DSH 对话可以用下方的会话查找命令检索。

## 查看进度和完成清单

| 想查看什么 | 可以怎么说 |
| --- | --- |
| 哪些任务需要我处理 | 「现在有哪些任务在等我」 |
| 哪些任务还在跑 | 「还有哪些对话在跑」 |
| 今天或近一周完成了什么 | 「今天完成了什么」或「最近完成了什么」 |
| 完成清单里某一条的结果 | 「查看完成清单第 2 项」 |

「今天」按上海时区计算，「最近」指过去 7 天。完成清单按有记录的结束时间列出结果，同一个子线程的多次回传可以分别查阅。编号命令使用当前会话最近一份清单。

## 查找具体回执

- **Mac 任务**。「查看 Mac 回执 回执编号」可读回 Dot 发起的任务结果。「D 那边进展怎么样」可查当前会话最近一次 Mac 执行的回执。
- **DSH 对话**。先说「查找 DSH 对话：标题关键词」，再用「查看 DSH 对话最新结果：标题关键词」。阅读历史轮次时，用清单中的对话 ID 和结束序号，例如「查看 DSH 结果 对话ID #结束序号」。从 Dot 发起的续办也可用「查看 DSH 续办结果 回执编号」。
- **QCA 子线程**。「查找云端任务：关键词」可在 Mac 桥接在线时查当前及迁移前的子线程。用「查看云端子线程结果 子线程ID」查最近结果，用「查看云端回传 事件ID」找特定一次回传。跨会话续办的结果也可用「查看旧云端续办结果 回执编号」读回。

QCA 当前会话的子线程可直接查询。Mac 离线期间，Dot 只能使用上次同步的任务本统计和观测时间来说明本机情况。重新连接后会先检查先前运行中或待处理的对话，缺少结束证据时显示「状态未确认」。

## 续办或停止

- 「在 DSH 对话『标题关键词』里继续：任务」会核对候选对话，经 Mac 审查后投递。匹配多条时，先选标题或精确 ID。
- 「停止 DSH 对话『标题关键词』」停止已有对话的当前轮，并保留对话历史和队列。DSH 内部子任务在父对话处理。
- 「让云端子线程 子线程ID 继续：任务」续办当前会话的云端子线程。「让旧云端子线程 子线程ID 继续：任务」经原会话转交，需要 Mac 桥接在线且原会话空闲。

在 DSH 宿主面板中可以点开已列出的本机对话。云端任务链接打开所属的 Qoder 会话。
