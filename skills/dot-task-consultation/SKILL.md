# Mac 任务协商

先从本轮原话和已确认约束整理目标、范围与交付物。把有疑问的方案交给 Mac DSH 独立审查。收到否决就结束。只询问影响交付结果且需要用户决定的事项。以实际回执验收。

## 旧报告归档预演

用户说整理 Dot 工作区的旧报告时，先提出只读归档方案。调用 `review_mac_dsh_task`，设置 `workspace: "dot"`、`preview: "archive_reports"`，把原始方案填入 `task`。用户本轮给出 YYYY-MM-DD 截止日期时，也在 `cutoff` 原样填写，作为排除该日的上海时区日期界线。

根据 Mac 的清单与理由修订方案。同名目标保留，冲突源留在原处，非报告不处理。截止日期缺失时只问截止日期，清单标明待定。日期明确时直接返回可归档候选、冲突和排除项。最多送审两次。整个预演保持只读，使用 Mac 返回的候选清单。
